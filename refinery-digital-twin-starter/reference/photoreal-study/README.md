# Archived photoreal study

This is the unchanged pre-consolidation study: its React scene, original stylesheet, exchanger/pump GLB, Cycles still and manifest are preserved as Task 4 reference. The live top tabs now switch appearance on the same whole-plant scene; this study is no longer shipped from the normalized public folder or mounted by the app.

The scene and manifest retain their original import and `preview/` URL paths as historical source. They are not a standalone executable application. The existing `blender/scripts/build_preview.py` remains the generator source; rebuilding that legacy preview can recreate its old output folder but does not reconnect it to the live app. No model, image or canonical plant data was regenerated for this archive.

The original `preview.css` is retained in the app for its unchanged top-tab rules, and copied here with the full historical study styling. Asset provenance and byte sizes are in the repository's `ASSETS.md`.

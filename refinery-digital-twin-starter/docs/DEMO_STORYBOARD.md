# Demo Storyboard

## Objective
Deliver a 3–5 minute premium interaction that can communicate its value in under 30 seconds.

## Scene 0 — Attract loop
- refinery emerges from darkness
- subtle scan/digital-twin overlay
- slow orbital camera
- sparse title: `Refinery Digital Twin`
- no branding

## Scene 1 — Explore
Hover: subtle outline + compact tag/name tooltip.
Click: camera ease, asset card, synthetic KPIs, nearby relationship highlight.
Hero assets: crude tank, transfer pump, exchanger, furnace, atmospheric column, overhead vessel, product tank, flare.

## Scene 2 — Process Trace
Select `Crude to Products`.
1. background dims
2. crude tank highlights
3. flow moves to pump
4. exchangers illuminate
5. furnace glows
6. column lights
7. product routes branch
8. camera moves between process steps

## Scene 3 — Data Layers
Layer menu: Health, Temperature, Energy, Emissions, Sensors.
Layer changes visual treatment while preserving plant readability.

## Scene 4 — Scenario
Select `Pump Trip`.
1. P-101A warning
2. alarm HUD
3. flow weakens/stops
4. downstream feed falls
5. affected assets highlight
6. activate standby
7. P-101B starts
8. flow returns
9. alarm resolves

## Scene 5 — Future-state teaser
Show compact future modules: Engineering Documents, Live Operations, Maintenance, AI Assistant.

## Presentation rule
Keep text sparse. The visual should explain the value before the presenter does.
